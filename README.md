# Steam Reception & Popularity Predictor — Streamlit Product

A complete, trained ML product built on the Steam Store dataset (26,564 games through May 2019),
with one Streamlit app serving two different audiences:

- **🛠️ Developer Studio** — forecast reception/reach for a game you're planning, explore price
  sensitivity, and see which features actually predict success.
- **🕹️ Player Corner** — find "hidden gem" games the crowd hasn't noticed, spot games where
  actual reception diverges sharply from what the model expects, and browse the catalog with
  model-backed quality signals layered on top of the raw data.

Both experiences share the same four trained XGBoost models under the hood.

## Quick start

```bash
pip install -r requirements.txt

# 1. Train the models (only needs to be run once — writes to models/)
python train_models.py

# 2. Launch the app
streamlit run app.py
```

Then open the local URL Streamlit prints (usually `http://localhost:8501`).

## What's under the hood

- **Data**: same cleaning pipeline as the analysis notebook — English-only, at least one review,
  developer/publisher reputation computed with **leave-one-out Bayesian shrinkage** (a game's own
  outcome is never used to compute its own reputation feature, which is the standard way this
  kind of feature leaks the label if you're not careful).
- **Models**: XGBoost for all four tasks (binary well-received classifier, 3-class reception-tier
  classifier, positive-ratio regressor, owners regressor), with hyperparameters selected via
  cross-validated random search in the companion analysis notebook and hard-coded here for fast,
  reproducible training.
- **Full-catalog scoring**: every game in the cleaned dataset is scored by all four models at
  training time and saved into `steam_clean.csv` — this is what powers the Player Corner's
  "hidden gems" and "over/underrated" features, comparing each game's *actual* outcome to what
  the model expected from its price/genre/platform profile alone.

## Model accuracy (honest numbers, not inflated)

| Task | Metric |
|---|---|
| Well-received (yes/no) | ROC-AUC 0.787 |
| Reception tier (Poor/Average/Great) | Accuracy 0.613 |
| Positive ratio (regression) | R² 0.269 |
| Owners (regression) | R² 0.652 |

These are moderate by design — pre-release metadata alone can't fully predict how players will
feel about a game. The app surfaces these numbers directly in the sidebar so nobody mistakes a
directional estimate for a guarantee. See the companion analysis notebook/README for the full
methodology and what was tried to improve accuracy.

## Known limitations

- **Data stops in May 2019.** Genre trends, pricing norms, and player expectations have shifted
  since — this is a historical pattern-matcher, not a live market signal.
- **`owners` is a bucketed estimate**, never an exact SteamSpy count, so the owners predictions
  inherit that same imprecision.
- **No text features.** Store descriptions, screenshots, and review text aren't used at all —
  this would likely be the single biggest accuracy lever if added.
- A brand-new developer/publisher with no track record is scored using the catalog-wide average
  reputation as a neutral default — the model has no way to know if you're the next great studio
  or a first-timer who'll struggle, and says so implicitly by giving you the average.
